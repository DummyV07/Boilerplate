## 模版说明

复制以下模板，每次部署时追加到文件末尾：

```markdown
## YYYY-MM-DD 部署记录

- **版本/分支**：
- **操作人**：
- **变更摘要**：
- **数据库变更**：无 / 需执行 xxx.sql
- **配置变更**：.env 新增/修改项
- **回滚方案**：git checkout <tag> && ./scripts/rollback.sh <commit>
- **部署结果**：成功 / 失败（附简要说明）
```
